# Firefly-hyde 页脚与主题面板移植

## 目标与来源

按用户提供的两幅截图，将分页下方的人物装饰、技术徽章和玻璃页脚，以及导航栏右侧的主题面板移植到本站。

参考仓库：[Seasir-Hyde/Firefly-hyde](https://github.com/Seasir-Hyde/Firefly-hyde)。页脚组件、样式和人物图片来自该仓库；保留 Firefly / Astro 的开源署名。

采用源码移植并适配本站配置：比整套替换更能保留本站的后台配置、壁纸布局和页面过渡；仅重画外观则会丢失原装饰资源与细节。截图已经明确目标设计，范围限于这两个区域。

## 组件与配置

- `Footer.astro` 放在主网格之后、Swup 容器之外。外层统一管理人物、徽章和页脚卡片，并参与沉浸阅读隐藏。
- 导航、作者、许可证与建站日期沿用本站配置。保留 `FooterConfig.html` 的自定义内容，以及 RSS / Atom / Sitemap 链接。
- 页脚的备案号是可选配置，默认空，不复制参考站的号码。未接入访问统计时显示 `--`。
- 原人物 WebP 本地保存，使用固定宽高、懒加载及响应式尺寸。样式兼容暗色与减少动画偏好。
- 运行时间兼容现有带时区的 ISO 日期与旧版日期格式，并防止无效日期或未来日期显示 NaN / 负数。
- 开启已有主题面板。外观页依次包含色相、文章布局、壁纸开关、卡片样式；壁纸页保留模式、全屏布局与参数滑块；特效页保留樱花开关。
- 沿用现有设置存储、浮层关闭、键盘操作与壁纸事件。列表/网格按钮明确选择对应布局。

## 后续确认的导航范围

顶部顺序采用用户追加截图：主页、归档、友链、动态、番剧、网址导航、相册、更多。其他保留入口集中到“更多”。桌面使用居中菜单与图标操作区，当前页面显示下划线；空间不足时转入移动菜单。

留言、分类、标签、系列的独立页面、组件、专用配置和入口删除，后台发布的旧菜单也会经过兼容整理。分类与标签仍是文章元数据，归档继续支持筛选；文章正文不变。“番剧”连接本站哔哩哔哩追番页，使用现有公开资料中的 UID。
