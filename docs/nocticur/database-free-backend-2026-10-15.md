# 无数据库后台改造回执（2026-10-15）

## 当前方案

博客、`/admin/`、`/api/` 和发布工作流仍属于同一个项目，统一构建和部署。正式文章与站点内容保存到 GitHub；后台运行状态保存为 Vercel Private Blob 中的私有 JSON 文件，不再使用 PostgreSQL 或其他数据库服务。

私有文件保存草稿及历史版本、站点与服务设置、登录会话及限流记录、互动审核、邮件队列、发布任务和备份索引。媒体文件继续使用原有的公有／私有 Blob 存储。

## 已完成的清理与替换

- 移除 PostgreSQL 驱动、SQL 访问模块、建表迁移文件、迁移命令及 CI 数据库服务。
- 内容、配置、鉴权、互动、邮件、媒体、发布及备份恢复模块已改为文件存储，数据库专用测试已替换为文件存储测试。
- 文件更新使用 Blob ETag 条件写入和冲突重试；记录操作标识，避免写入成功但确认丢失时重复执行；拒绝不安全的对象键。单个状态文件限制为 16 MiB。
- 保留登录验证、同源与 CSRF 校验、预览／开发与生产存储隔离。生产发布、邮件和维护开关仍默认关闭，只能由登录管理员在后台修改。
- 保留发布租约及任务校验、GitHub 基线校验、外部请求结果不明时的核对流程，以及邮件发送幂等保护。
- 恢复前验证文件并创建安全备份，最终写入检查状态是否发生并发变化。恢复保留当前服务开关及不可逆的服务回执，清除登录会话，阻止旧的未完成任务直接重放。

## Vercel 环境变量

已从 `firefly` 项目删除最后一个空的数据库变量 `ADMIN_PRODUCTION_DATABASE_URL`。重新读取后，项目由 9 条变量记录减少至 8 条，未发现数据库变量，保留的变量均未填写实际值。

基础后台需要填写：

- `ADMIN_ENTRY_PASSWORD`：后台登录密码。
- `BLOB_PRIVATE_READ_WRITE_TOKEN`：保存后台私有 JSON 文件和备份的存储令牌。

GitHub 发布、公有媒体、验证码等功能按需填写相应凭据。环境、站点来源和服务开关按当前代码自动推导或由后台设置，无须数据库地址、建表或迁移。完整说明见 [环境变量说明](environment-variables.md)。
