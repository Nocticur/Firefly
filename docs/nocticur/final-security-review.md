## 本次修复

| 确认的问题 | 修复与影响 |
| --- | --- |
| 入口尚未满足用户指定的 3～10 字符与后台自动加盐哈希要求 | 前后端统一按 Unicode 字符接受 3～10 位，拒绝全空白、非法 Unicode 和超长输入。服务端自动使用 32 字节随机盐及 scrypt（N=32768、r=8、p=1），异步验证并恒定时间比较；限流通过后才计算候选哈希。缓存只保留派生值，不向客户端或数据库交付密码/验证哈希。Cookie 密钥独立派生，支持跨实例会话 |
| 主题密码文章在 `sessionStorage` 保存明文阅读密码并自动读取解锁 | 取消保存、读取和自动解锁；清理旧缓存时只删除对应键。提交后立即清空输入；刷新后需要重新输入阅读密码 |
| 密码文章的 AES-GCM 盐与 IV 由密码/slug 确定，多次构建和编辑会复用同一密钥与 nonce | 每次加密使用随机 16 字节盐和 12 字节 IV，保留可在浏览器验证的 AES-256-GCM 格式。测试覆盖独立解密、重复构建、内容修改、错误密码及密文/盐/IV/tag 篡改 |
| Biome CI 未显式限制 `GITHUB_TOKEN` 权限，工具使用 `latest`；checkout 会保留 Git 凭据 | 两个 CI 均为 `contents: read`，checkout 设置 `persist-credentials: false`，Biome 固定为 2.5.12；动作仍按提交 SHA 固定。新增文章加密回归步骤 |
| 根目录只忽略两种 `.env` 文件，其他本地环境文件可能误提交 | 改为忽略 `.env*`，只允许 `.env.example` 模板 |
| 部署构建未在仓库命令中统一禁止 Astro 匿名遥测，构建命令可通过 `npx` 临时获取执行器 | Astro 命令通过本地 Node 包装器强制 `ASTRO_TELEMETRY_DISABLED=1`；构建使用已安装且由锁文件约束的 `pnpm exec tsx`。安装前的 pnpm 检查改为本地脚本，不下载执行器。管理 Nitro 显式关闭 `tracingChannel`，产物不含向平台导出 spans 的插件 |
| 此前环境准备启动的 Astro 开发服务仍监听 127.0.0.1:4321 | 核实 PID、项目目录与 `astro dev` 参数后关闭。最终检查没有博客/管理开发端口；保留已知的 loopback 测试 PostgreSQL 与云平台进程 |

环境变量 `ADMIN_ENTRY_PASSWORD` 仍由平台保存原密码，程序不会把 Vercel 变量改写为哈希，也不能消除服务端处理登录时的短暂明文。传输需要 HTTPS，环境变量只配置在管理项目的服务器侧。填写方法见 [环境变量清单](./environment-variables.md)，进入页与实际登录验收见 [admin-entry-review.md](./admin-entry-review.md)。

## API、令牌与授权检查

- 对当前仓库文本、博客 `dist` 和管理 `.vercel/output/static` 做只读模式扫描，覆盖 GitHub/AWS/Blob/Resend/OpenAI/Slack/Google 常见凭据格式、完整 PEM 私钥与 URL 内嵌密码。公开产物未命中管理密码变量、本地合成登录密码或上述凭据格式。唯一受跟踪的环境文件是空值模板 `apps/admin/.env.example`；没有提交实际 `.env`。
- 当前源码命中均为 `media.test.ts` 中模拟 Blob 命名空间的假令牌和被拒绝的 `user:pass@allowed.invalid` 测试地址。对本次修订前本地全部 1444 个可达提交做扩展模式变更检索，命中上述测试和旧 Twikoo 的 AWS 官方示例；已核实示例位于配置说明，未发现真实 AWS 凭据。未查询其账户或使用扫描命中进行认证。扫描不覆盖远端未拉取引用、已删除的不可达对象、二进制中的秘密或任意无固定格式的密码。
- 全部 **41 个 OpenAPI 管理操作**分别使用匿名与伪造 Cookie/Authorization/CSRF/身份请求真实 Hono 应用，均返回 401 和 `no-store`；测试刻意不配置数据库，证明拒绝发生在私有读取之前。会话别名不能绕过；公开入口状态和 OpenAPI 不返回密码或服务器验证哈希。
- 登录只验证密码，没有用户名、外部 OAuth、隐含第二登录方式或默认生产密码；旧 GitHub 登录/回调为 404，旧数字身份会话不再有效。合法登录创建随机会话，数据库保存令牌及 CSRF 摘要；客户端不能指定管理员身份。注销、密码轮换、过期、环境隔离、写入 Origin/CSRF 和持久并发限流均有实际覆盖。
- `/api/media/upload` 的上传令牌请求仍要求管理认证、CSRF 与有效私有上传意图；服务商完成回调使用 SDK 签名核验与意图归属检查。Resend Webhook 使用签名认证；维护 Cron 使用独立 Bearer 密钥。这些服务回调不因不使用管理员 Cookie 而成为匿名授权入口，相关验证包含在媒体/邮件/维护测试中。
- GitHub App 向官方 API 请求限于 `Firefly` 的安装令牌；读取用 Contents read，发布用 Contents write，目标固定为 `Nocticur/Firefly/master`，可写路径有白名单。Vercel、Blob、Neon、Resend 和 Turnstile 权限用于文档列明的业务；项目没有给第三方自动安装 App、添加协作者、修改账户角色或为访客授予管理权限的路径。**真实平台的 App 安装范围和服务 token 权限尚未核验**，代码无法收回用户在平台额外授予的权限。

此后台按用户要求使用一个管理密码；知道它的人具有完整后台管理能力。3 位密码很容易猜测，捕获的有效 Cookie 也可能用于离线猜测密码。scrypt、HTTPS、两种 HttpOnly Cookie 与每 IP 5 次/10 分钟及全站 100 次/10 分钟的限流提供保护，但不增加原密码的熵。建议在允许范围内使用 **10 位随机密码**；密码轮换后重新部署管理项目。

## 后台任务与数据访问

| 行为 | 触发条件、数据与边界 |
| --- | --- |
| 发布 Workflow | 管理员显式发布并满足生产开关；任务只携带任务 ID，读取冻结快照、提交约定仓库文件并核验生产版本，最多 1440 次、每次等待 1 分钟 |
| 邮件 Workflow | 已授权通知和正式邮件开关；读取通知 ID 对应收件地址/内容交给 Resend，最多 8 次受控重试；未知发送结果不任意重发 |

| 代码与数据读取 | 服务端按名称读取配置的环境变量，连接对应环境数据库；导入仅读取约定仓库路径；媒体导入需要管理员操作及精确 HTTPS 主机、公网 DNS 固定、禁止跳转和大小/总超时限制。未发现读取 SSH/AWS 密钥、浏览器个人配置、任意主机文件或扫描无关用户目录的业务代码 |
| 浏览器访问 | 管理请求保持同源，CSRF 只在内存中；密码不进浏览器存储。文件选择、粘贴与复制属于用户主动编辑操作。主页与保护文章的实际浏览器检查没有请求定位、麦克风、摄像头或自动读取剪贴板，没有向第三方请求附带凭据头 |

| 云工作区进程 | 验证服务按脚本退出，旧 Astro 服务已关闭。观察到的持续进程为云环境代理/Codex/Docker 和隔离 PostgreSQL；测试数据库只绑定 127.0.0.1:5433。另有已退出的 defunct 记录，它们不再执行代码或网络请求；本次没有重启平台 PID 1 或干预平台服务 |

公开互动只返回约定公开字段，邮箱、会话、私有草稿、备份和媒体原图不写入公开发布清单。正式邮件、发布、生产维护及公开评论的开关未配置时保持关闭。后台读取这些私有数据是已实现的管理功能，不意味着能访问用户其他账户或设备的数据。

4. 媒体已有格式/大小/SVG/摘要检查，但没有完整像素解码或病毒扫描。私有历史和备份仍需容量监控、保留策略与 Blob 对象字节备份。此前 [迁移安全复审](./security-review.md) 的相关限制继续适用。
